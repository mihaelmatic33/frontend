# Product Images — `data/images/`

Place your product image files here before running the importer.
Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`

The importer will read each file by name, upload it to the WordPress Media Library,
and store the resulting media ID in `acf.product_image`.
